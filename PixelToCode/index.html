Conversor de Unidades CSS

Convierte dinámicamente entre píxeles (`px`), `rem`, `em` y porcentaje (`%`) tomando como base la escala configurada.

Resultado de la Conversión:

1 rem

Fórmula: 16px / 16px = 1rem

Código CSS equivalente:

font-size: 1rem; /* equivalente a 16px */
